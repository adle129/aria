## 2. 模块展开表

| 列 | 宽度 | 内容 |
|----|------|------|
| 纳入 | 70 | 行 Checkbox；表头 Checkbox = 本模块全选 |
| 维度 | 160 | `name` |
| 工作内容 | flex | Input（`in_scope` 时）；否则 `—` |
| RFQ 依据 | 240 | `§章节 标题` 或 `关键词「…」`；点击 → Drawer |
| 匹配方式 | 120 | Tag：`source_label` |
| 状态 | 100 | 系统推荐 / 自动纳入 / 已纳入 / 未纳入 |

**模块标题行示例：**

```
[车身]  已纳入 3 项 · 2 项自动纳入 · 1 项系统推荐纳入 · 1 项待确认  （3/3 已勾选）· 2 项已排除  [已过目]
```

**可见行规则：**

- 模块级：含 `in_scope`、`needs_review` 或 `auto_include` 任一条目即展示  
- 行级：展开后展示该模块**全部**基准行（含 `auto_exclude`）

## 4. 确认门禁与按钮状态

| 条件 | 提示 |
|------|------|
| `in_scope < 1` | 禁用确认；「至少勾选 1 项维度后方可确认」 |
| 含 in_scope 模块未展开 | 「请先展开【{模块}】模块过目」 |
| `needs_review` 且 in_scope 未 ack | 「还有 N 项待确认未处理」 |
| 全部满足 | 主按钮可点：「确认以上例外，生成对比矩阵」 |

**ack 规则（v1.2）：** 勾选 `in_scope` → ack；取消勾选 → 清除 ack；编辑工作内容 → ack。无独立「确认此项」按钮。

## 5. 视觉规范

| review_tier | 状态列文案 | in_scope=false 时 |
|-------------|-----------|-------------------|
| auto_include | 自动纳入 / **系统推荐** | 系统推荐（绿色 Tag） |
| needs_review | 已纳入（蓝色 Tag） | 未纳入 |
| auto_exclude | — | 未纳入 |

| match_type | source_label |
|------------|--------------|
| keywords | 关键词匹配 |
| module_scope | 模块范围推断 |
| llm | AI 语义匹配 |
| none | — |
