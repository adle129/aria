# ARIA 智能报价辅助系统 — 用户操作手册

**版本：** v1.1  
**日期：** 2026-06-20  
**适用对象：** 报价工程师

---

## 1. 系统简介

ARIA 是本地部署的 AI 报价辅助工具，覆盖 EDAG 报价流程的 **四大输出**：

| 输出 | 系统页面 |
|------|---------|
| 历史技术对标 | RFQ 分析 |
| 技术方案草案 | 技术方案 |
| 待澄清技术问题 | 澄清问题 |
| 人力报价预测 | 人力报价 |

**重要：** AI 输出仅为参考草稿，导出前请务必人工审阅确认。

**Demo 说明：** RFQ 解析、历史对标、Excel 生成为 **真实 AI 能力**。「技术方案」「澄清问题」及人天构成明细在 Demo 阶段为 **预览界面（Mock 数据）**；详见 [demo-scope-brief.md](demo-scope-brief.md)。界面中标有 **「Demo 预览」**。

## 2. 访问系统

- **内网地址：** http://aria.company.internal（或部署方提供的地址，如 http://localhost）
- **远程访问：** 先连接公司 VPN，再访问上述地址
- **浏览器：** 推荐 Chrome / Edge 最新版

## 3. 五步工作流程

```
① RFQ 分析 → ② 历史对标（同页） → ③ 技术方案 → ④ 澄清问题 → ⑤ 人力报价
```

每个业务页面顶部有 **当前任务** 栏与 **五步进度条**。请先上传 RFQ 并完成解析，再依次审阅各步 AI 草稿。

### 3.1 ① RFQ 分析

1. 进入左侧 **「RFQ 分析」**
2. 在 **「最近分析」** 中选择历史任务，或上传新的 `.docx` RFQ
3. 等待 AI 解析（约 1–5 分钟，页面显示进度）
4. 查看 **Function 模块**、交付物、里程碑
5. 查看 **技术维度对比表**（3–5 个相似历史项目）及置信度
6. 点击相似项目行可 **展开** 查看方案摘要（Demo 可能为 Mock 片段）
7. 编辑对比表 → **保存修订** → 勾选确认
8. 点击 **「下一步：技术方案」** 或左侧导航继续

**置信度：** 🟢 高 / 🟡 中 / 🔴 低（低置信度须重点人工核对）

### 3.2 ③ 技术方案（Demo 预览）

1. 进入 **「技术方案」**（须已选定 RFQ 任务）
2. 点击 **「生成方案草案」**
3. 按 Function 查看匹配的 **历史技术模块卡片**（假设/输入/工作内容/交付物）
4. 每卡片显示来源项目、相似度、偏差率（Demo 为示例数据）
5. 可在文本区做初步编辑
6. 继续 **「澄清问题」**

### 3.3 ④ 澄清问题（Demo 预览）

1. 进入 **「澄清问题」**
2. 点击 **「生成 QA 清单」**
3. 查看表格：序号、Area、问题、影响程度、历史依据
4. 可编辑、删除条目；正式版支持导出 Q_A Excel
5. 继续 **「人力报价」**

### 3.4 ⑤ 人力报价

1. 进入 **「人力报价」**
2. 确认当前任务与项目信息
3. 勾选 **导出确认**
4. 点击 **「生成 Excel 报价初稿」**（真实生成，通常 < 1 分钟）
5. **下载** `.xlsx`；在 Excel 中进一步调整
6. 查看 **人天构成明细** 预览表（Demo 为 Mock，展示「交付物 → 贡献人天」形态）

> Demo 阶段 Excel 仅自动填充 **PM** 和 **Chassis** 两个 Function Sheet；构成明细与全 Function 在正式版提供。

---

## 4. 任务切换与历史记录

- 各页面顶栏 **「当前任务」** 下拉可切换最近 RFQ 分析记录
- **RFQ 分析** 页 **「最近分析」** 列表显示文件名、时间、处理状态
- 切换 tab（如去知识库再返回）后，系统会恢复上次选中的任务

---

## 5. 知识库（管理员）

### 5.1 导入历史文档

1. 将历史项目文档放入服务器 `knowledge_base/<项目名>/` 目录
2. 进入 **「知识库」** → **刷新统计** / **触发导入**（若已接线）
3. 查看文档数、项目数

### 5.2 原子模块目录（Demo 占位）

正式版将在此浏览按 Function 拆解的历史方案模块。Demo 阶段为占位说明。

### 5.3 支持的文档

- Word：RFQ、技术方案
- Excel：历史报价、Q_A 清单

## 6. 注意事项

| 事项 | 说明 |
|------|------|
| AI 是辅助 | 所有对外文件必须人工审核 |
| Demo 预览 | 方案与 QA 页 Mock 内容不可直接对外 |
| 低置信度 | 标红结果须重点校验 |
| 文件格式 | Demo RFQ 仅支持 .docx |
| 明细保密 | Excel 人力明细仅内部使用 |

## 7. 常见问题

**Q: 上传后一直「解析中」？**  
A: 正常 1–5 分钟；超过 10 分钟请联系 IT 检查 Ollama。

**Q: 技术方案/QA 内容看起来是固定的？**  
A: Demo 为界面预览；正式版接入贵司历史库后由 AI 生成。

**Q: 切换页面后结果不见了？**  
A: 请用顶栏任务下拉或 RFQ 页「最近分析」重新加载任务。

**Q: Excel 部分人天为空？**  
A: Demo 仅 PM+Chassis；正式版支持全部 Function。
