# ARIA 智能报价辅助系统 — 用户操作手册

**版本：** v1.0  
**日期：** 2026-06-18  
**适用对象：** 报价工程师

---

## 1. 系统简介

ARIA 是本地部署的 AI 报价辅助工具，帮助您：

- 自动解析客户 RFQ，拆解工作模块
- 检索相似历史项目，生成技术维度对比表
- 生成 Excel 人力报价初稿

**重要：** AI 输出仅为参考草稿，导出前请务必人工审阅确认。

---

## 2. 访问系统

- **内网地址：** http://aria.company.internal
- **远程访问：** 先连接公司 VPN，再访问上述地址
- **浏览器：** 推荐 Chrome / Edge 最新版

## 3. 基本操作流程

```
上传 RFQ → 查看 AI 分析结果 → 审阅编辑 → 确认定稿 → 生成 Excel → 下载
```

### 3.1 上传 RFQ

1. 进入「RFQ 分析」页面
2. 点击「上传 RFQ」或拖拽 `.docx` 文件
3. 等待 AI 解析（约 1–5 分钟，页面会显示进度）
4. 解析完成后自动展示结果

### 3.2 查看分析结果

**Function 模块列表：** AI 从 RFQ 中识别的工作领域（PM、Chassis 等）及交付物。

**技术维度对比表：** 与 3–5 个最相似历史项目的逐项对比。

| 列 | 说明 |
|----|------|
| 技术维度 | 平台类型、材料、仿真类型等 |
| 新项目 | 当前 RFQ 的要求 |
| 历史项目 A/B/C | 相似度百分比 + 各维度值 |
| ✓/✗ | 是否匹配 |

**置信度标识：**

- 🟢 **高** — 可参考性较强
- 🟡 **中** — 建议重点核对
- 🔴 **低** — 无足够历史参考，须人工判断

**来源引用：** 点击历史项目名可查看引用的原始文档片段。

### 3.3 审阅与编辑

1. 检查 AI 解析的 Function 和模块是否准确
2. 检查对比表中的历史项目是否确实相关
3. 可直接在页面上编辑对比表内容
4. 对不准确的引用可备注（Phase 2 支持「标记不准确」）

### 3.4 确认定稿

1. 审阅完成后，勾选「**本人已审阅确认，AI 内容仅供参考**」
2. 点击「确认定稿」
3. 状态变为「已确认」后方可导出

### 3.5 生成 Excel 人力报价

1. 进入「报价生成」页面
2. 确认项目信息和里程碑
3. 点击「生成 Excel 报价初稿」
4. 等待生成（通常 < 1 分钟）
5. 点击「下载」获取 `.xlsx` 文件
6. 在 Excel 中进一步调整后用于内部复核

> Demo 阶段仅自动填充 PM 和 Chassis 两个 Function Sheet，其余 Sheet 保留模板结构。

---

## 4. 知识库（管理员）

### 4.1 导入历史文档

1. 将历史项目文档放入服务器 `knowledge_base/<项目名>/` 目录
2. 进入「知识库管理」页面
3. 点击「增量导入」
4. 查看导入结果（新增文档数/chunk 数）

### 4.2 支持的文档

- Word：RFQ、技术方案
- Excel：历史报价、Q_A 清单

**提示：** 知识库越丰富，AI 检索越准确。建议每个完成的项目都导入。

---

## 5. 注意事项

| 事项 | 说明 |
|------|------|
| AI 是辅助 | 所有对外文件必须人工审核，不得直接发送客户 |
| 低置信度 | 标红结果须重点校验 |
| 文件格式 | Demo 仅支持 .docx RFQ |
| 明细保密 | Excel 人力明细仅内部使用，对外仅提供总价 |
| 数据安全 | 系统完全内网运行，数据不出企业 |

## 6. 常见问题

**Q: 上传后一直显示「解析中」？**  
A: 正常需 1–5 分钟。超过 10 分钟请联系 IT 检查 AI 服务状态。

**Q: 没有找到相似历史项目？**  
A: 可能是知识库中无相关项目，请联系管理员导入更多历史文档。

**Q: Excel 中部分人天为空？**  
A: Demo 阶段仅填充 PM 和 Chassis，正式版将支持全部 Function。

**Q: 能否修改 AI 生成的内容？**  
A: 可以。请在导出前在页面上编辑，确认后再下载。
