**版本：** v1.1 · 2026-07-07  
**用途：** 了解贵司日常工作习惯，便于我们配置合适的系统能力  
**填写说明：** 无标准答案，请按平时真实情况选择最接近的选项；不确定处可留空，会议时一并讨论。  
**预计用时：** 约 5–10 分钟  

---

## 一、为什么需要了解这些

ARIA 报价助手部署在贵司内网，工程师上传招标文件后，系统会自动分析、检索历史项目并辅助生成报价相关文件。

**分析一份招标文件通常需要约 1–2 分钟。** 若多人同时在用，后面的请求需要依次排队处理。  
我们希望根据贵司**实际使用习惯**选择合适的设备配置和使用方式，避免「太慢」或「功能与预期不符」。

## 四、访问方式与隐私

> **说明：** R1 正式版采用 **账号登录 + 任务隔离 + 两角色**。工程师仅见本人 RFQ 任务；资料库检索全员可用，导入/重建索引仅管理员。

### 5. 大家打开系统后，是否需要「每人只看到自己的项目」？

- [ ] **不需要** — 同事之间看到彼此的项目也可以

### 6. 是否需要「每人单独账号登录」？

- [ ] **不需要** — 公司内网能打开就用
- [ ] **需要登录** — 但不用分很细的权限
- [x] **需要分角色** — 例如：普通工程师 / 负责维护资料库的管理员 ← 客户确认

> **说明：** 「登录」管「谁能看到谁的项目、谁能改资料库」；「几个人同时用会不会慢」靠排队和设备，两件事分开考虑。

## 六、R1 正式版方案（2026-07-07 定稿）

| 项目 | R1 方案 |
|------|---------|
| 访问方式 | 公司内网（或 VPN）→ **登录页** |
| 账号登录 | **须** 每人单独账号（IT 预置 10–20 个） |
| 角色 | **`quote_engineer`**（默认）/ **`kb_admin`**（资料库维护） |
| RFQ 任务可见性 | **每人仅见本人任务** |
| 知识库 | **全公司共享检索**；写操作仅 `kb_admin` |
| 同时修改 | 同一任务若多人同时改，以最后保存为准；建议一项目一人负责改 |
| 多人同时用 | 单 worker 排队；页面显示 **排队位置 / 预计等待** |
| 推荐硬件 | **推荐版**（32 核 / 128G / RTX 4090） |

**不含于 R1（可选运维包）：** SSO/AD 集成、部门级权限、任务委派。
