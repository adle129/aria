**版本：** v1.0 · 2026-07-06  
**用途：** 了解贵司日常工作习惯，便于我们配置合适的系统能力  
**填写说明：** 无标准答案，请按平时真实情况选择最接近的选项；不确定处可留空，会议时一并讨论。  
**预计用时：** 约 5–10 分钟  

---

## 一、为什么需要了解这些

ARIA 报价助手部署在贵司内网，工程师上传招标文件后，系统会自动分析、检索历史项目并辅助生成报价相关文件。

**分析一份招标文件通常需要约 1–2 分钟。** 若多人同时在用，后面的请求需要依次排队处理。  
我们希望根据贵司**实际使用习惯**选择合适的设备配置和使用方式，避免「太慢」或「功能与预期不符」。

## 四、访问方式与隐私

> **说明（发客户前可读）：** 当前默认是内网打开即用、不要求登录，操作简单。但同事之间**可以看到彼此的任务**；若两人**同时修改同一任务**，以**最后保存为准**。建议每个投标项目**指定一位同事**在系统里修改，其他人先看、讨论即可。若希望「各看各的」或「分角色管理」，请在下面选 B 或 C。

### 5. 大家打开系统后，是否需要「每人只看到自己的项目」？

### 6. 是否需要「每人单独账号登录」？

- [ ] **不需要** — 公司内网能打开就用（**当前方案默认**）
- [ ] **需要登录** — 但不用分很细的权限
- [ ] **需要分角色** — 例如：普通工程师 / 负责维护资料库的管理员

> **说明：** 「登录」主要管「谁能看到谁的项目、谁能改资料库」；「几个人同时用会不会慢」主要靠排队和设备，两件事可以分开考虑。

## 六、当前方案默认（供对照，无需勾选）

| 项目 | 当前首期方案 |
|------|-------------|
| 访问方式 | 公司内网（或 VPN）打开即可使用 |
| 账号登录 | 不要求每人单独登录 |
| 任务可见性 | 使用同一系统的同事可看到彼此的任务列表 |
| 同时修改 | 同一任务若多人同时改，以最后保存为准；建议一项目一人负责改 |
| 资料库维护 | 建议由 1–2 名指定人员负责导入与更新 |
| 多人同时用 | 系统自动排队，页面会显示等待情况 |

若第 5、6 题选择与上表不同，我们会单独评估是否需要调整方案（可能涉及额外开发与费用）。
