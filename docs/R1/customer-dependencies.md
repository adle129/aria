## 维度对比表准确度 · 客户输入（必读）

> **产品结论：** 对比矩阵的业务准确度，主要取决于客户提供的「尺子」与「核对样例」，而不是再堆一层模型。当前系统内种子维度清单仅用于流程打通，**不能**替代下列交付物做矩阵业务验收。

| 优先级 | 客户输入 | 没有它会怎样 |
|--------|----------|--------------|
| **必须** | **O-01** 正式工作维度清单（业务认可的名称与模块） | 矩阵「比什么」口径不对；只能验流程，不能验业务正确 |
| **强烈建议 · R1-β 矩阵签字建议关闭** | **O-01a** 每个维度在历史 RFQ 里的常见章节叫法 / 别名 | 系统只能按「名字像不像」对章节 → 空格偏多，难区分「没写」和「叫法不同」 |
| **验收必备** | **O-01b** 在 2～3 份真实（或脱敏）历史 RFQ 上，按维度标注：应有摘录 / 应为空 / 仅标题异名 | 无法客观判定矩阵格子对错；「未匹配到对应章节」无法验收 |
| 与现有项协同 | **O-02a / O-04** 提供可对标的历史/新 RFQ 样例 | 无样例则无法联调与签字演练 |

**业务读法（便于贵司内部传达）：**

1. 维度清单 = 统一比对尺子（要不要比这项，以勾选为准）。  
2. 别名对照 = 告诉系统：这项工作在历史文档目录里通常叫什么。  
3. 单元格金标准 = 人工事先标好「这个格子该有内容还是该空」，用来验收系统，而不是只看流程跑通。  
4. 「未匹配到对应章节」应读作：**在当前尺子下没对上章节证据**；有别名表 + 金标准后，才能区分是规则问题还是历史确实未写。

模板列与邮件说明见 [rfq-dimension-baseline-spec 附录 A](../supplementary/rfq-dimension-baseline-spec.md)。

## 交付物说明

### O-01 工作维度基准清单

- Excel：模块分类 + 维度名称（约 80–120 项，以贵司实际为准）  
- **正式业务口径**；导入后替换我方种子版  
- 详见附录 A.1～A.3

### O-01a 维度 ↔ 历史章节别名对照

- 可与 O-01 **同一工作簿**第二张表，或单独 Excel  
- 每行：维度名称（或维度 ID）+ 历史 RFQ 常见章节标题 / 同义叫法（可多条）  
- 用途：提升「历史项目在该维度写了什么」的命中率，减少因叫法不同导致的空格  
- 详见附录 A.4

### O-01b 矩阵单元格金标准

- 选定 **2～3 份**历史 RFQ（优先与 O-02a 脱敏套或内网可对标样例重叠）  
- 对 O-01 中拟纳入验收的维度，逐格标注期望：  
  - **应有摘录**（并尽量注明期望章节名或关键词）  
  - **应为空**（历史确实未写该项）  
  - **标题异名**（有内容但目录叫法与维度名不同 — 应回填到 O-01a）  
- 用途：R1-β **矩阵准确度**联合调优与签字依据；无此表则矩阵仅作流程验收

### O-02a 脱敏金标准（P1 · ≥5 套）

- **完整三件套**（RFQ + Q&A + **填好数**报价 Excel）
- **已脱敏**，供开发/格式验证；**逐套**验收（失败=0）
- **不要求** bulk 每套达到此标准

### O-02b 结构试点（P1 · 10–20 套）

- **脱敏**；**允许缺件**（代表 bulk 真实形态）
- 统计失败率 Top5 → 选定 bulk 档位 A/B/C

### O-02c 内网 bulk（P2）

- **贵司现有历史项目库** — 规模以 **O-02d 清点表 N** 为准（目前沟通约 **数十至百级**，**不写死**）
- **原始资料仅在贵司内网** `${ARIA_DATA_ROOT}` 处理
- 乙方：目录规范、manifest、**远程** import 联调、导入报告
- R1 签字（档位 A）：清点表范围内 **≥90%** 已落盘 engagement 成功索引；**银/铜**可缺件
- 详见 [bulk-import-workload-assessment.md](bulk-import-workload-assessment.md)

### O-02d 历史项目清点表

| 字段 | 说明 |
|------|------|
| 计划入库项目数 **N** | 双方确认；**不预设为 100** |
| 三件套齐全率（估） | 影响 M3/M4 预期 |
| 缺件类型分布 | RFQ-only / 缺报价 / 缺 Q&A 等 |
| R1 bulk 验收范围 | 哪些目录/批次纳入第 7–8 周签字 |

### O-03 / O-04 / O-05

见 [R1 验收说明（客户版）](../R1-知识库验收与检索评测说明（客户版）.md) v1.6。  
**O-04** 建议与 **O-01b** 选用同一批或重叠的代表性 RFQ，避免重复准备样例。
