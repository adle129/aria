## 交付物说明

### O-02a 脱敏金标准（P1 · ≥5 套）

- **完整三件套**（RFQ + Q&A + **填好数**报价 Excel）
- **已脱敏**，供开发/格式验证；**逐套**验收（失败=0）
- **不要求** bulk 每套达到此标准

### O-02b 结构试点（P1 · 10–20 套）

- **脱敏**；**允许缺件**（代表 bulk 真实形态）
- 统计失败率 Top5 → 选定 bulk 档位 A/B/C

### O-02c 内网 bulk（P2）

- **贵司现有历史项目库** — 规模以 **O-02d 清点表 N** 为准（目前沟通约 **数十至百级**，**不写死**）
- **原始资料仅在贵司内网** `${ARIA_DATA_ROOT}` 处理
- 乙方：目录规范、manifest、**远程** import 联调、导入报告
- R1 签字（档位 A）：清点表范围内 **≥90%** 已落盘 engagement 成功索引；**银/铜**可缺件
- 详见 [bulk-import-workload-assessment.md](bulk-import-workload-assessment.md)

### O-02d 历史项目清点表

| 字段 | 说明 |
|------|------|
| 计划入库项目数 **N** | 双方确认；**不预设为 100** |
| 三件套齐全率（估） | 影响 M3/M4 预期 |
| 缺件类型分布 | RFQ-only / 缺报价 / 缺 Q&A 等 |
| R1 bulk 验收范围 | 哪些目录/批次纳入第 7–8 周签字 |
