## 一句话

**第一期（第 8 周）签字后，贵司工程师即可在内网用真实历史项目库做 RFQ 技术维度对标（Top-3 对比矩阵）——无需等到 20 周全部功能上线。**

---

## 第一期结束您能做什么

| 能力 | 第一期 | 说明 |
|------|--------|------|
| 历史项目入库 | **是** | ≥5 套金标准 + **贵司现有历史项目库**（套数以清点表为准） |
| 上传 RFQ → 确认 ~100 项维度 → Top-3 对比矩阵 | **是** | **日常可用**（RFQ 分析页） |
| 知识库：试搜历史、核对人天、上传补录 | **是** | 知识库管理页；≥15 条检索试搜 |
| 人力 Excel 自动生成 | 第二期 | 共用同一历史库 |
| Q&A 清单导出 | 第三期 | 同上 |
| Tech Proposal PPT 预填 | 第四期 | 同上 |

---

## 网页上具体有什么（速览）

| 打开菜单 | 做什么 |
|---------|--------|
| **知识库** | 看入库多少套 · 查文件是否成功 · **试搜**历史 · **核对**报价人天 · 上传 1～5 套补录 |
| **RFQ 分析** | 上传新 RFQ → 找 3 个最相似历史项目 → 确认维度 → 出对比表 |

**不含：** 开发调试页、拖拽整文件夹上传、按项目代号精确搜名字。

---

## 贵司需要提供

| 时间 | 内容 |
|------|------|
| 签约后 **1 周内** | **≥5 套**脱敏金标准三件套；另 **10–20 套**结构试点（可缺件） |
| **签约后 2 周内** | 双方确认 **《历史项目清点表》**（计划入库套数；**不写死具体数字**） |
| **第 5–8 周** | IT 在 **内网** 存放真实历史库（**原始资料不出公司网络**） |
| **第 4 周前** | 共同确认 **≥15 条**检索试搜题 |
| **第 7–8 周** | **内网** 3 份 RFQ 对标流程试用与签字 |

---

## 第一期验收看什么

1. **≥5 套金标准**进库（失败=0）+ 人天数字可核对  
2. **批量导入报告**（清点表范围内默认 **≥90%** 成功；**缺件项目可入库**）  
3. **3 份 RFQ** 全流程 + 检索试搜 **≥12/15** 通过  
4. **明确不含**：第二期 Excel、第三期 Q&A、第四期 PPT  

---

## 为什么不是「只放 3 套样品」

Top-3 对标需要在 **足够多、有差异** 的历史项目中排序才有业务意义。第一期因此要求 **≥5 套金标准逐套验收**，并在 **内网** 建立 **贵司现有历史项目库**（**不要求** 每一套都人工对数；**不要求** 每套都有完整三件套）。
