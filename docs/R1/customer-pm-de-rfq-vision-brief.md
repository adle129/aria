# 给客户项目经理 · PDF/PPT 红旅图与德语 RFQ 能力说明（非技术版）

**版本：** v0.1 · 2026-07-23  
**用途：** 与客户 PM 沟通范围、两种做法、本地硬件与预算参考  
**详细技术评估：** [pdf-ppt-de-rfq-vision-eval.md](pdf-ppt-de-rfq-vision-eval.md)  
**说明：** 下文价格为 **2026 年中市场参考区间**，硬件由贵司自购；成交价以招标/经销商报价为准。软件开发费用需待样本验证后另报变更单。

---

## 一、用大白话说清楚：你们要的是什么

现在系统主要像「读 Word 说明书」：工程师上传文字版 RFQ，系统整理需求，并和历史项目做对比，辅助报价。

贵司新需求更接近德国主机厂常见做法：

1. **文件不只是 Word**，还有 **PDF、PPT**；  
2. 里面常有「**红旅图**」：用绿 / 红 / 黄标出零件是沿用、新设计还是要改；系统要尽量认出图上的字和颜色；若图上没有文字标签，就把彩色零件图抽出来，让工程师对照补全；  
3. 内容经常是 **德语**；还要能和库里已有的 **中文、英文、德语** 历史项目找到相似的，作为报价参考。

**当前第一期交付做不到上述能力**；需要单独立项评估，**不影响正在进行的第一期进度与验收**。

## 二、两条路怎么选（先问清一件事）

| | **做法 A：请外部 AI 帮忙看图** | **做法 B：全部在贵司电脑里完成（本地大模型）** |
|--|------------------------------|-----------------------------------------------|
| 像什么 | 把页图发给有资质的云端 AI 服务「认字认颜色」，结果再拿回系统 | 在贵司机房自己的 AI 服务器上认图、认德文 |
| 资料是否离开公司 | **一般要出内网**（须信息安全批准） | **不出内网**（更贴合现有「私有化」承诺） |
| 上线速度 | 通常更快 | 要加装/升级设备，验证周期更长 |
| 持续费用 | 按使用量付给云服务商 | 主要是电费与设备折旧，无按次云费用 |
| 额外电脑要求 | 现有推荐服务器通常够用 | **需要更强的显卡配置**（见下一节） |

**建议先和贵司信息安全确认：** 红旅图、德文 RFQ **能不能离开内网**。  
- 不能 → 只能走 **做法 B**；  
- 能且书面批准 → 可走 **做法 A**，或 A/B 混合（例如仅看图走云、历史对比仍留本地）。

## 三、若选本地大模型：硬件怎么配、大概多少钱

> 以下为 **整机参考价（含税口径请以采购为准）**，单位：人民币。  
> 不含：机房改造、UPS、多年质保加价、软件开发与实施费。

### 3.1 和「现在第一期推荐配置」的关系

第一期生产推荐（仅 Word 文本、中英为主）大致是：

| 项目 | 建议 |
|------|------|
| 显卡 | NVIDIA **RTX 4090 24GB × 1** |
| 处理器 / 内存 | 约 32 核级 / **128GB** |
| 硬盘 | 系统盘约 1TB + **数据盘 ≥4TB**（知识库与备份） |
| **整机预算参考** | **约 6–10 万元** |

这套配置适合当前第一期；**不足以舒适支撑「大量德文带图 RFQ + 红旅图」日常使用**（一张卡要兼顾「读文字」和「看图」，人一多就会明显排队变慢）。

### 3.2 本地方案分档（针对新需求）

#### 档位 L1 · 试点 / 小流量（可先验证，不建议当德国客户主路径）

| 项目 | 建议 |
|------|------|
| 思路 | **沿用现有 1 张 4090**，软件上「看图」和「读文字」错开排队 |
| 适用 | 每月少量德文带图样例、内部试认、可行性验证 |
| 体验 | 忙时等待会变长；不适合「多数德国 RFQ 都是带图」 |
| **增量硬件** | 若已有第一期机器：**约 0 元**；若尚未采购：同第一期 **6–10 万元** |
| 显卡单卡市价参考（2026 年中） | RTX 4090 24GB 约 **2.0–2.5 万元** / 张（渠道波动大） |

#### 档位 L2 · **推荐生产档（德国带图 RFQ 作为主路径时）**

| 项目 | 建议 |
|------|------|
| 思路 | **两张显卡分工**：一张专心读文字/整理需求，一张专心看红旅图 |
| 显卡 | **RTX 4090 24GB × 2**，或 **RTX 5090 32GB × 2**（若采购 5090 更易） |
| 处理器 / 内存 | 32 核级以上 / **128–256GB** |
| 电源与机箱 | 需满足双卡供电与散热（IT 按双卡工作站/塔式或机架选型） |
| 硬盘 | 系统盘 ≥1TB；数据盘 **≥4TB**（页图缓存与模型体积更大，建议预留充足） |
| **整机预算参考** | **约 12–18 万元** |
| 若已有第一期单卡机器、只加第二张卡 | 增量大约 **2.5–4 万元**（含可能更换电源/机箱，以 IT 评估为准） |
| 显卡单卡市价参考 | 4090 约 **2.0–2.5 万**；5090 约 **2.4–3.5 万**（型号与渠道差异大） |

#### 档位 L3 · 单卡大显存（运维更简单、采购看货源）

| 项目 | 建议 |
|------|------|
| 思路 | **一张大显存专业卡**同时放下「读文字 + 看图」（减少换卡排队） |
| 显卡示例 | **RTX A6000 48GB** 或同级 48GB 工作站卡 |
| 处理器 / 内存 | 32 核级 / **128–256GB** |
| **整机预算参考** | **约 10–16 万元** |
| 显卡单卡市价参考 | A6000 48GB 常见报价约 **3.3–4.0 万元** 量级（以当时经销商为准） |

### 3.3 怎么跟贵司 IT 说「买哪档」

| 贵司情况 | 建议档位 |
|----------|----------|
| 先试几份德文带图 RFQ，确认值不值得上 | **L1** |
| 德国客户是主业务，带图 PDF/PPT 很常见 | **L2（推荐）** |
| 希望少维护两张卡、货源能买到 48GB 专业卡 | **L3** |
| 信息安全允许图纸出网、想少买显卡 | 优先评估 **做法 A**，硬件可维持第一期 6–10 万档 |

## 四、费用结构（避免误解）

| 费用项 | 谁承担 | 说明 |
|--------|--------|------|
| 服务器 / 显卡 | **贵司自购** | 上表为参考价，不是我方软件报价 |
| 本能力软件开发与实施 | **变更单另报** | 需先拿真实样例做小范围试认，再估人天 |
| 做法 A 的云端识别 | **贵司按量付给云厂商** | 用得越多费用越高；须安全审批 |
| 第一期已签范围 | 不变 | 本需求 **不自动包含**在第一期里 |

## 五、建议的下一步（给 PM 的行动清单）

1. 确认：**图纸和德文 RFQ 能否出内网**（决定 A 还是 B）。  
2. 提供：**不少于 5 份**脱敏真实样例（含红旅图的 PDF 或 PPT；最好再加 1–2 份德文文字页）。  
3. 说明：希望输出是 **Excel 清单** 还是系统里勾选确认即可。  
4. 我方做小范围试认后，再出具：**软件变更报价 + 最终硬件档位确认**。  
5. **第一期继续按原计划**，本项单独立项、单独排期。

## 六、一页纸口述稿（会上 1 分钟版）

> 现在系统主要处理 Word 文字 RFQ。德国常见的是 PDF/PPT 里带彩色变更图，还经常是德文，还要和中英文历史项目找相似项——这是额外能力，第一期没有包含。  
> 有两条路：资料可以出公司，就用外部 AI 看图，电脑不用大升级，但要安全批准和按次付费；资料不能出公司，就在本地做，建议按「两张显卡」或「一张大显存卡」采购，整机大概十二到十八万，或在现有机器上再加一张卡大约三万上下。  
> 建议先定能不能出网，再给几份样例试认，再谈软件费用和上线时间。
