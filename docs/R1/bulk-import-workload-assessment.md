# 客户历史项目库批量导入 — 工作量评估与验收档位

**版本：** v1.1 · 2026-07-06  
**索引：** [r1-usability-delivery-strategy.md](r1-usability-delivery-strategy.md) · [validation-corpus.md](validation-corpus.md)

> **Bulk Corpus：** 贵司 **现有历史项目库**；规模 **以双方《历史项目清点表》（O-02d）为准**（目前沟通约 **数十至百级**，**不写入合同固定数字**）。

---

## 1. 目的

在 R1 签字前选定 **内网 bulk 导入** 的验收口径：评估乙方工作量、避免「逐套 baselines 人工全检」不可行，同时保证客户 **R1 签完即可在内网用历史库做 RFQ 对标**。

**两阶段：**

- **P1（脱敏）：** 金标准 + 结构试点 — 开发/格式验证，**可离开内网**（已脱敏）。
- **P2（内网）：** 原始历史项目库 — **仅在贵司 GPU 服务器** import，R1 **第 7–8 周验收**。

---

## 2. 单套流水线：自动 vs 人工

| 步骤 | 方式 | 单套耗时（估） |
|------|------|----------------|
| IT 内网落盘 + manifest | 客户 IT + 乙方规范/脚本 | 批量摊薄 |
| RFQ 切块 + 向量化 | **自动** | 秒–分钟 |
| Q&A 按行索引 | **自动** | 秒级 |
| 报价 → baselines | **自动** + 规则校验 | 秒级；异常需人工 |
| 缺件分级（金/银/铜） | **自动** 导入报告 | — |
| baselines 与 Excel 逐项核对 | **人工** | **30–60 min/套** |
| RFQ 切块 spot check | **人工**（**仅金标准**） | 15–30 min/套 |
| Top-3 / 15 题评测 | **抽样** | 不按 bulk 全库逐套 |

**结论：** bulk **禁止**逐套 baselines 全检。金标准 **5 套** 逐套检；bulk 依赖 **导入报告 + 失败类修复 + 10% 或 10 套随机审计**。**不要求** bulk 每套完整三件套。

## 3. 乙方工作包与人日（粗估）

| ID | 工作包 | 人日 | 阻塞 R1 签字 |
|----|--------|------|--------------|
| W1 | 目录规范与 manifest 模板 | 2–3 | 是 |
| W2 | 客户 **内网** IT 落盘联调（远程） | 2–4 | 是 |
| W3 | 内网首次 import + re-index | 1–2 | 是 |
| W4 | 失败类治理（按错误类型修 parser/规范） | 3–10 | 视档位 |
| W5 | 金标准 5 套深度验收（**脱敏**，P1） | 3–5 | 是 |
| W6 | 批量抽样审计（10% 或 10 套） | 1–2 | 档位 A 可选 |
| W7 | Top-3 + 15 题评测（**内网**语料） | 2–3 | 是 |
| W8 | **历史项目清点表**（O-02d）对齐 | 0.5–1 | 是 |

**Bulk 相关合计：** 约 **14–30 人日**。须选档位；不可「清点表 N 全量 + 全检 + 8 周固定价」三者兼得。

## 4. 验收档位 A / B / C

| 档位 | R1 签字条件 | 工作量 | 风险 |
|------|-------------|--------|------|
| **A · 可用优先（默认）** | 金标准 **≥5** + **清点表确认的内网 bulk 范围**内 **≥90%** 已落盘 engagement 成功索引 + 导入报告 + 3 份 RFQ 对标 | W1–W5 + W7–W8；W4 修 Top 失败类 | ~10% 例外须书面清单 |
| **B · 全量硬杠** | 清点表 **N 全部**进库（银/铜可缺件） | W1–W7 全量 | N 大时 **8 周/固定价不够** |
| **C · 分阶段** | R1 签：**≥5 金标准 + 内网首批 ≥30 或清点表 50%**；**R1+4 周** 完成剩余内网入库 | R1 做 W1–W3+W5+W8 | 需客户接受签字后收尾 |

**内部决策（2026-07-06）：** 默认 **档位 A**；试点失败率 >15% 或需大规模 parser 改造时，改 **档位 C** 或 **R1+1 周变更单**。

**R1 签字仍须：** 内网 **≥15 indexed RFQ**（推荐）+ ≥12/15 检索；bulk 规模 **随清点表 N**，不绑定固定项目数。

## 6. 与客户沟通要点

1. **不写死项目数** — 以 **清点表 N** 为准（目前约百级以内）。  
2. **不要求 bulk 全套件** — 缺 Q&A/报价可 **银/铜** 入库。  
3. **P1 脱敏 + P2 内网** — 开发用脱敏样本；**签字在内网**用真实历史库。  
4. **原始资料不出网** — 乙方远程协助规范与联调。
