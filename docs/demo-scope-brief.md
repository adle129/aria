# ARIA Demo 范围说明（一页纸）

**面向：** EDAG 业务负责人、报价工程师、IT  
**版本：** v1.0 · 2026-06-20  
**详细基线：** [prod.md §9](../prod.md)

---

## 本次 Demo 要证明什么

1. **完整报价 AI 工作流可被理解** — 从 RFQ 到人力 Excel 的五步路径清晰可用  
2. **核心 AI 能力可运行** — RFQ 解析、历史对标、Excel 初稿在贵司环境可重复演示  

---

## 五步流程

```
RFQ 分析 → 技术方案 → 澄清问题 → 人力报价 → （知识库）
   ①           ②           ③           ④
```

每个业务页顶部显示 **当前任务** 与 **进度条**，便于在多页之间切换而不丢失上下文。

---

## 两档验收

| | 框架档 | 能力档 |
|---|--------|--------|
| **目的** | 看见产品全貌 | 验证真实 AI |
| **RFQ 解析 + 历史对标** | 真实 | 真实 |
| **Excel 人力（PM+Chassis）** | 真实 | 真实 |
| **技术方案草案** | **界面预览（Mock）** | Phase 2 真实 |
| **QA 澄清清单** | **界面预览（Mock）** | Phase 2 真实 |
| **依赖 GPU/Ollama** | Stub 部分不需要 | 需要 |

Mock 区域界面标 **「Demo 预览」**，请勿当作最终 AI 质量或对外交付物。

## 明确不在本次 Demo

- 历史方案 **真实原子化** 检索与拼接  
- QA / 方案的 **真实 LLM 质量** 与 Q_A Excel 正式导出  
- PPT 方案导出  
- 全部 9 个 Function Sheet、交付物级 **真实** 人天基线  
- PDF/Excel 格式 RFQ 上传  

以上在 **Phase 2 正式版** 交付，**沿用同一套 UI 与 API 形状**，替换 Mock 为真实 AI。

---

## 演示话术（建议）

> 今天演示的是完整五步工作流。RFQ 解析、历史对标和 Excel 是真实 AI；技术方案和 QA 页面展示的是正式版的数据结构与交互，内容为 Demo 预览，Phase 2 接入贵司历史知识库后，在同一界面替换为 AI 生成结果。
