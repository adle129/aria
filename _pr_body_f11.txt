## Summary

实现 F1.11 RFQ 分析协作取消，并优化侧栏任务筛选体验。

- **Phase 1**（`queued` / `parsing`）：`POST /api/v1/rfq/tasks/{id}/cancel` 协作取消，终态 `cancelled`，清理部分产物；支持 `retry` 重新解析
- **Phase 2**（`retrieving` / `generating`）：标 `cancelling` 软状态，在 LLM / RAG / embedding 安全边界回滚 `dimension_review`，保留维度勾选
- **协作机制**：`TaskJob.cancel_requested_at` + `CooperativeCancelled`；LLM 流式 generate 并在取消时关闭 HTTP 连接释放 Ollama 租约；query embedding 支持 `cancel_check`；DB 轮询节流 0.5s
- **前端**：解析进度条取消按钮 + 确认 Modal；`cancelling` / `cancelled` 轮询与 CTA；侧栏筛选项改为「失败 / 已取消」合并筛选
- **文档**：`prod.md`、`api-design.md`、`dev-tasks`（R1-F11）、验收清单、测试计划、追溯矩阵
